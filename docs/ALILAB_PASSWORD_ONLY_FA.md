# ورود و ثبت‌نام AliLab با رمز عبور

در نسخهٔ ساده‌شده، ثبت‌نام فقط نام کاربری، رمز عبور و تکرار آن را می‌خواهد؛ ایمیل اختیاری است. کد دعوت، پس‌کی، اتصال برنامهٔ موبایل با کد و افزودن دستگاه دیگر از رابط AliLab حذف شده‌اند. ورود مجدد پس از پایان نشست نیز فقط رمز عبور می‌خواهد.

## تنظیم API در استقرار

- `PASSWORD_ONLY=1`: ورود با رمز را فعال، دعوت را غیرفعال و مسیرهای پس‌کی، دعوت و اتصال دستگاه را با پاسخ 404 مسدود می‌کند. این مقدار بر `INVITE_ONLY=1` یا `PASSWORD_LOGIN=0` قدیمی اولویت دارد.
- `INVITE_ONLY=0` و `PASSWORD_LOGIN=1`: برای شفافیت تنظیمات هم‌راستا نگه داشته شوند.
- `ALLOW_GUEST=0`: ورود به حساب برای دسترسی به برنامه همچنان الزامی است.

تغییر هم به انتشار API و هم به انتشار Web نیاز دارد. انتشار Web به‌تنهایی شرط دعوت API قدیمی را برنمی‌دارد. تنظیم‌های دیسک، بک‌آپ، دامنه و secret نشست تغییری نمی‌کنند.

ثبت‌نام بدون دعوت برای هر بازدیدکننده‌ای که سایت را می‌بیند باز است. ثبت‌نام خودکار نقش مدیر نمی‌دهد؛ مالک جدید باید با شناسهٔ دقیق حساب از مسیر عملیاتی مدیریت به مدیر تبدیل شود. محدودیت تلاش ورود، هش رمز، کنترل مبدأ، نشست و جداسازی دادهٔ کاربران برقرار می‌مانند.

پیش از فعال‌سازی روی سروری با حساب واقعی، مطمئن شوید همهٔ حساب‌های موردنیاز رمز عبور دارند؛ حسابی که فقط پس‌کی داشته با این حالت امکان ورود ندارد. داده‌ها و اعتبارنامه‌های قدیمی از پایگاه داده حذف نمی‌شوند. حالت سازگار API بدون `PASSWORD_ONLY=1` برای نصب‌های قدیمی حفظ شده است، ولی رابط AliLab فقط ورود با رمز ارائه می‌دهد.
