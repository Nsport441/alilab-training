# پاک‌سازی وابستگی‌ها و آماده‌سازی بک‌آپ AliLab

تاریخ: ۱۴ اکتبر ۲۰۲۶. مبنا: انتشار کاتالوگ، commit `0062da4`.

## وابستگی‌ها

ابزار قدیمی و استفاده‌نشدهٔ `@capacitor/assets` از وابستگی‌های توسعه حذف شد. این ابزار برای
آیکون‌های وب/PWA لازم نیست؛ SVG و PNGهای AliLab در مخزن نگه‌داری می‌شوند. تولید آیکون برای
انتشار بومی احتمالی باید جداگانه بازبینی شود. راهنمای موبایل نیز این تغییر را توضیح می‌دهد.

چهار lockfile با به‌روزرسانی‌های سازگار در محدودهٔ نسخه‌های موجود اصلاح شدند. audit کامل
فرانت‌اند، API با optional، MCP و ریشه در زمان این بررسی صفر آسیب‌پذیری شناخته‌شده گزارش کرد.
این نتیجه وابسته به پایگاه advisory در زمان بررسی است و تضمین نبودن آسیب‌پذیری ناشناخته نیست.
CI اکنون هر چهار بخش را با `--audit-level=low` بررسی می‌کند و تست و قابلیت بارگذاری MCP را
پیش از آزمون کانتینرها اجرا می‌کند. وابستگی‌های اجرایی پیش‌فرض API تغییر نکرده‌اند.

## پوشهٔ آرشیوهای خصوصی

برای جلوگیری از ورود کلید یا آرشیو قبلی به snapshot بعدی، فقط با گزینهٔ صریح
`--exclude-backup-artifacts` پوشهٔ ریشهٔ `/data/.alilab-backups` کنار گذاشته می‌شود. این پوشه
باید یک دایرکتوری معمولی باشد؛ symlink رد می‌شود. نام پوشه در manifest رمزنگاری‌شده ثبت می‌شود.
رفتار پیش‌فرض همچنان تمام فایل‌های داده را شامل می‌شود و خروجی داخل مسیر داده را رد می‌کند.

پس از توقف کامل نویسندهٔ API و تأیید نبودن ابرک نویسندهٔ قبلی:

```sh
node scripts/alilab-encrypted-backup.mjs create /data /data/.alilab-backups/backup.enc /private/key.bin --api-stopped --exclude-backup-artifacts
node scripts/alilab-encrypted-backup.mjs restore /data/.alilab-backups/backup.enc /private/restored /private/key.bin --api-stopped
```

پوشهٔ مقصد و فایل کلید ۳۲ بایتی باید از قبل با دسترسی خصوصی آماده شوند. گزینهٔ
`--api-stopped` فقط تأیید اپراتور است؛ سرور را متوقف نمی‌کند. کلید داخل snapshot یا خروجی
فرمان چاپ نمی‌شود. بازیابی آزمایشی در مسیر مستقل انجام می‌شود و دادهٔ زنده بازنویسی نمی‌شود.
نسخهٔ روی همان volume بک‌آپ خارج از میزبان نیست. انتقال به مقصد مستقل و نگه‌داری قابل بازیابی
کلید، با تعیین سرویس ابری و اتصال آن، عملیات جداگانهٔ ضروری‌اند. اطلاعات خصوصی، کلید و
آرشیو واقعی نباید وارد GitHub یا بستهٔ وب شوند.

## بررسی

۳٬۱۹۶ تست فرانت‌اند، ۴۷۱ تست API با دو skip پلتفرمی محلی، ۶۳ تست MCP و چهار تست عملیاتی
موفق شدند. build تولیدی، برابری localeها، checksum رسانه و قابلیت بارگذاری MCP نیز موفق بودند.
تست جدید ثابت می‌کند کلید و آرشیو قبلی از بازیابی حذف می‌شوند و پوشهٔ symlink رد می‌شود.
این‌ها بررسی ابزار و برنامه‌اند؛ نتیجهٔ بک‌آپ واقعی و مقصد مستقل در گزارش خصوصی عملیات ثبت می‌شود.
