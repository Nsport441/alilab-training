# AliLab Training — بازسازی مرحلهٔ کاتالوگ و مرور تمرین

تاریخ: ۱۴ اکتبر ۲۰۲۶. مبنا: `1eeb6a5c05d070ffc0a882bdbf3f86c6a799c466`، PR شمارهٔ ۴.
این پیاده‌سازی تازه از مبنای ثبت‌شده بازسازی شده است؛ فایل‌های نسخهٔ ازدست‌رفته بازیابی نشده‌اند.

## رفتار نسخه

- ۳۸۱ مقدار باقی‌ماندهٔ رابط فارسی بازنویسی شدند. اصطلاح‌های RIR، RPE، ATG و نام‌های رسمی
  Face ID و iCloud Keychain حفظ می‌شوند. انتخاب زبان، RTL، ارقام فارسی و تقویم شمسی قبلی برقرارند.
- ۱٬۳۲۴ نام فارسی به‌صورت لایهٔ نمایش اضافه شدند. نام انگلیسی و جست‌وجوی هر دو زبان حفظ می‌شوند.
  نام حرکت سفارشی کاربر حتی در برخورد شناسه با کاتالوگ، ترجمه نمی‌شود. فایل اصلی داده تغییر نکرده است.
- نام‌ها با واژه‌نامه و عبارت‌های ورزشی قابل بازتولید ساخته شده‌اند؛ برای حرکت‌های کم‌کاربرد، عنوان
  انگلیسی همچنان مرجع تشخیص دقیق نوع حرکت است. وجود نام فارسی به معنی بررسی تخصصی همهٔ حرکت‌ها نیست.
- ۲۸۰ راهنمای کوتاه فارسیِ نوشته‌شده برای AliLab در خانواده‌های مشخص حرکت اضافه شده‌اند. این‌ها
  ترجمهٔ کامل مرحله‌های انگلیسی نیستند. راهنمای کامل انگلیسی زیر یک بخش بازشونده حفظ شده است.
  حرکت‌های فاقد راهنمای فارسی، راهنمای انگلیسی را با برچسب صریح نشان می‌دهند.
- ۳۸ تصویر ثابت و تغییرنیافته از Everkinetic، دریافت‌شده از wger، برای ۱۹ حرکت مشخص بسته‌بندی شده‌اند.
  مجوز هر تصویر CC BY-SA 3.0 است. مؤلف، منبع، پیوند مجوز و SHA-256 در registry ثبت شده‌اند؛
  انتساب در صفحهٔ حرکت نیز نمایش داده می‌شود. فقط شناسه‌های صریح registry رسانه دارند؛
  فایل‌های خام upstream، VITE CDN overrides و شناسه‌های سفارشی نمی‌توانند رسانهٔ عمومی اضافه کنند.
  تصاویر دوم با دکمهٔ قابل استفاده از کیبورد قابل مشاهده‌اند. کلیپ یا GIF اضافه نشده است.
- رنگ سطوح تیره و روشن، نشان SVG و آیکون‌های نصب AliLab اضافه شدند. انتخاب رنگ تأکیدی حساب،
  شناسهٔ نصب، start URL و scope تغییر نکرده‌اند. فونت ثالث از شبکه دریافت نمی‌شود.
- کارت آمار، پنجرهٔ ۲۸ روز تقویمی شامل امروز را با ۲۸ روز پیش از آن مقایسه می‌کند: جلسه، روز تمرین،
  ست کاری، دقیقهٔ ثبت‌شده و حاصل وزنهٔ ثبت‌شده در تکرار. ست گرم‌کردن و کار ناتمام کنار گذاشته می‌شوند؛
  هر سمتِ کامل‌شدهٔ حرکت یک‌طرفه با وزنهٔ همان سمت محاسبه می‌شود. حجم ذخیره‌شدهٔ قدیمی مرجع نیست.
  تاریخ آینده و نامعتبر کنار گذاشته می‌شوند و شناسهٔ تکراری یک بار شمرده می‌شود.
  با مقدار صفر در دورهٔ پیشین، درصد رشد ساختگی نمایش داده نمی‌شود.
  این کارت فقط مشاهده‌های ثبت‌شده است؛ وزن بدن به حاصل وزنه × تکرار اضافه نمی‌شود و محاسبهٔ ریکاوری نیست.
- ابزار آفلاین `scripts/alilab-encrypted-backup.mjs` یک snapshot معتبر را با AES-256-GCM
  و nonce تصادفی رمزنگاری می‌کند. کلید ۳۲ بایتی باید در فایل خصوصی جدا باشد. بازیابی به پوشهٔ خالی،
  تأیید اصالت رمزنگاری و checksum تمام فایل‌ها را پیش از کپی نیاز دارد. فایل موجود بازنویسی نمی‌شود.
  نسخهٔ فعلی برای Linux و حداکثر ۱۲۸ MiB دادهٔ خام در نظر گرفته شده است.

## بک‌آپ خارج از میزبان

این انتشار ابزار را فراهم می‌کند؛ بک‌آپ واقعی سرور یا ارسال خودکار به فضای ابری اجرا نمی‌کند.
سرویس ابری، اتصال، نگهداری کلید و زمان‌بندی هنوز باید تعیین شوند. کلید، env، state، فایل secret،
snapshot و بک‌آپ زنده نباید در GitHub یا بستهٔ وب قرار گیرند.

نمونهٔ اجرای آفلاین پس از توقف نویسندهٔ API و تأیید نبودن ابرک نویسندهٔ قبلی:

```sh
node scripts/alilab-encrypted-backup.mjs create /data /private/backup.enc /private/key.bin --api-stopped
node scripts/alilab-encrypted-backup.mjs restore /private/backup.enc /private/restored /private/key.bin --api-stopped
```

`--api-stopped` تأیید اپراتور است؛ ابزار خودش سرور را متوقف نمی‌کند. بازیابی آزمایشی باید ابتدا
در مسیر مستقل انجام شود. کلید در خروجی فرمان چاپ نمی‌شود و باید جدا از آرشیو نگهداری شود.

## بررسی و انتشار

بررسی‌ها شامل آزمون‌های کامل فرانت‌اند/API، build، تساوی کلیدها و placeholderهای ۱۷ locale،
checksum رسانه، جست‌وجوی فارسی/انگلیسی، حفظ متن سفارشی، مرز تاریخ و ست یک‌طرفه، snapshot/restore
و رد کلید اشتباه و دست‌کاری بک‌آپ هستند. CI همان کد دقیق شاخه را دوباره بررسی می‌کند.

فقط بستهٔ وب از commit آزموده‌شده روی سرویس وب موجود Runflare منتشر شود. API، volume، حساب،
مجوزها و تنظیمات امنیتی فعلی برای این مرحله تغییری نیاز ندارند. سورس متناظر همراه وب باقی می‌ماند.
پس از انتشار، سلامت API، metadata سورس، manifest، رسانهٔ ثبت‌شده و 404 مسیرهای قدیمی کنترل شوند.
