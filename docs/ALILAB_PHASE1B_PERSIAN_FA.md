# AliLab Training — ادامهٔ فاز ۱B، ۱۳ اکتبر ۲۰۲۶

## نقطهٔ ادامه

فاز صفر و زیرساخت فاز ۱A انجام شده‌اند. PR شمارهٔ ۳ در ۱۲ اکتبر با commit
`1a1cf0d5389ff0f9bafdf4fba35abfba3f4c9670` ادغام و هویت AliLab روی وب Runflare منتشر شد.
گزارش عملیاتی پیشین ثبت یک تمرین، همگام‌سازی، بازیابی مستقل و ماندگاری داده را تأیید می‌کند.
شاخهٔ فارسی/شمسی هنوز در مخزن وجود نداشت؛ این تغییر ادامهٔ همان مرحله است.

## رفتار این نسخه

- فارسی و English در صفحهٔ ورود و فارسی در تنظیمات زبان قابل انتخاب‌اند. جهت فارسی RTL
  و جهت English، LTR است. انتخاب زبان حساب، همان تنظیم قابل همگام‌سازی موجود است.
- ۱٬۳۲۵ رشتهٔ رابط به فارسی نوشته شده‌اند؛ ورود، تمرین، برنامه، تاریخچه، وزن، تنظیمات و
  پیام‌های همگام‌سازی پوشش دارند. ۳۸۱ رشتهٔ باقی‌مانده، عمدتاً Coach و مثال‌های demo،
  با fallback انگلیسی صریح باقی مانده‌اند؛ این نسخه ترجمهٔ کامل همهٔ قابلیت‌ها نیست.
- نام و راهنمای اجرای حرکاتِ کاتالوگ انگلیسی باقی می‌مانند. نام‌های سفارشی کاربر تغییر
  نمی‌کنند. RPE، RIR و e1RM در متن فارسی حفظ و توضیح داده می‌شوند.
- نمایش تاریخ، روزهای هفته، تقویم ماهانه، نمودار و نقشهٔ فعالیت در فارسی از تقویم Persian
  مرورگر استفاده می‌کنند. نمایش تقویم شمسی صرفاً تغییر نمایش است؛ ISOهای ذخیره‌شده،
  timestampها، ID تمرین‌ها و قرارداد همگام‌سازی تغییر نمی‌کنند.
- تقویم ماهانه، شمارش و جزئیات همان ماه شمسی را نشان می‌دهد؛ مثلاً مهر ۱۴۰۵ از
  `2026-09-23` تا پیش از `2026-10-23` است.
- انتخاب یا ویرایش تاریخ تمرین گذشته در فارسی با تاریخ `YYYY/MM/DD` یا انتخاب‌گر
  شمسی انجام می‌شود. ارقام فارسی و عربی پذیرفته می‌شوند. تاریخ ناقص، نامعتبر،
  غیرکبیسه یا پس از امروز قابل ذخیره نیست؛ مقدار معتبر قبلی پشت ورودی نامعتبر نمی‌ماند.
- ورودی عددی مشترک، ارقام فارسی/عربی و ممیز `٫` را می‌پذیرد و عدد معمول JS ذخیره می‌کند.
- شروع هفته از شنبه هم قابل انتخاب است. زبان به‌تنهایی شروع هفتهٔ حساب قبلی را عوض
  نمی‌کند؛ دوشنبه/یکشنبهٔ انتخاب‌شده حفظ می‌شود.
- از فونت نصب‌شدهٔ Tahoma/Segoe UI استفاده می‌شود؛ درخواست فونت به سرویس ثالث اضافه نشده.

## محدوده و ادامه

انتخاب‌گر تاریخ شمسی سال‌های ۱۲۰۰ تا ۱۶۰۰ را پشتیبانی می‌کند. تبدیل رفت‌وبرگشت با یک
پیاده‌سازی واحد `Intl` انجام می‌شود. آزمون‌ها مرز نوروز، اسفند کبیسه/غیرکبیسه،
۴۰۰ روز متوالی، حفظ ISO، تاریخ‌های آینده و ارقام فارسی/عربی را پوشش می‌دهند.
موفقیت بررسی یکسان‌بودن کلیدهای locale به معنی تکمیل ترجمهٔ همهٔ متن‌ها نیست.

این تغییر frontend است و به مهاجرت یا راه‌اندازی مجدد API نیاز ندارد. محیط موجود staging
است. بک‌آپ خارج از میزبان، ترجمهٔ باقی‌مانده، ترجمهٔ نام/راهنمای حرکت‌ها، آیکون و پوستهٔ
اختصاصی و رسانهٔ دارای مجوز هنوز کارهای بعدی‌اند. Coach، آپلود سرور و ورود مهمان مطابق
تنظیمات قبلی غیرفعال می‌مانند. مبنای قواعد پیشرفت و محاسبهٔ حجم تغییر نکرده است.

برای انتشار، فقط بستهٔ وبِ commit آزموده‌شده روی سرویس `82353` بارگذاری شود؛ سرویس API
`82352` و volume داده نیازی به تغییر ندارند. پس از انتشار، نسخهٔ سورس متناظر، سلامت
API، بستهٔ فارسی، manifest و مسیرهای مسدود رسانه بررسی شوند.
