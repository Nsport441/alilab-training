# Persian catalogue batch 14

This batch adds Persian names and 1,585 instruction steps for 300 existing upstream exercises. We translated the names and new steps from the fixed English catalogue and reused 686 previously reviewed steps matched by English text. We deferred 31 candidates with unclear setup or redundant entries. Independent exercise-specialist review is pending.

The batch increases localization coverage to 3,808 of the 4,308 upstream exercises. It changes the Persian text overlay and adds 23,988 bytes to that overlay under gzip. It uses the existing IDs, English guides, media and notices. Tests validate original and translated hashes, numeric values and search in both languages.
