# Persian translation batch 12

Adds Persian names and instructions for 400 independent imported exercises
(2,209 steps), increasing coverage from 2,708 to 3,108 of 4,308. The assistant
compared the translations with the pinned English source; independent exercise
specialist review remains pending. Twenty-three ambiguous candidates were
deferred, and 22 replacements were selected. Prior deferred IDs remain excluded.

The manifest binds source and translation hashes. Automated tests check
uniqueness, instruction counts, numerical values, bilingual search, English
fallback and previous translations; they do not establish translation quality.
Exercise identifiers, user data, saved plans, media, licenses and offline
configuration are unchanged. Overlay growth: 258,441 source bytes and
38,286 gzip bytes (source-file
measurements). Based on commit 8df352a7c8ba29bf4d6a5080051a2cbb5f8c8071.
