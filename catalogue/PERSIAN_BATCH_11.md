# Persian translation batch 11

This batch adds Persian names and instructions for 400 independent imported
exercises (2,049 steps), increasing coverage from 2,308 to 2,708 of 4,308.
The assistant compared translations against the pinned English source.
Independent review by an exercise specialist remains pending.

Eleven records were deferred due to ambiguities in their source descriptions
and replaced. Prior deferred IDs remain excluded. The manifest binds original
and translated text with SHA-256 hashes. Automated checks cannot establish
translation quality.

Exercise IDs, user data, saved plans, media, licenses and service worker
configuration are unchanged. Overlay growth: 263,971 bytes source and
37,383 bytes compressed
(source-file measurements). Based on commit f7f35f488afc98b3fe067ae4e7560bc96f9a627e.
