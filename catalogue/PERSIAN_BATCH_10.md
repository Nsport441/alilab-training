# Persian translation batch 10

This batch adds Persian names and instructions for 390 independent imported
exercises (2,196 steps), increasing coverage from 1,918 to 2,308 of 4,308.
The assistant compared 1,524 steps with the pinned English source and reused
672 previous translations for matching instructions. Independent review by an
exercise specialist remains pending.

Records 3306, 3490 and 7592 were deferred due to ambiguity or inconsistency
in their source descriptions and replaced. Prior deferred IDs remain excluded.
The manifest binds source and translated text with SHA-256 hashes. Tests check
uniqueness, instruction counts, numbers, bilingual search, English fallback and
previous translation integrity; automated checks do not establish translation quality.

No exercise IDs, user data, saved plans, media, licenses or service worker
configuration are changed. The overlay grows by 237,899 bytes in source and
31,448 bytes gzip-compressed (source-file measurements, not a network benchmark).
The batch is based on commit 240b32a77c8916561c3a920a6cab6fd4c9c075b0.
