# Persian translation batch 09

This batch adds Persian names and instructions for 400 independent imported
exercises (2,029 steps), increasing coverage from 1,518 to 1,918 of 4,308.
The assistant compared 1,369 steps with the pinned English source and reused
660 previous translations for matching instructions. Independent review by an
exercise specialist remains pending.

Records 3410, 5399, 5451 and 5554 were deferred due to ambiguity in their
source descriptions and replaced. Prior deferred IDs remain excluded. The
manifest binds source and translated text with SHA-256 hashes. Tests check
uniqueness, instruction counts, bilingual search, English fallback, and prior
translation integrity; automated checks do not establish translation quality.

No exercise IDs, user data, saved plans, media, licenses or service worker
configuration are changed. The overlay grows by 245,333 bytes in source and
29,657 bytes gzip-compressed (source-file measurements, not a network benchmark).
The batch is based on commit e91345e760c5044f968f3f6b325963aa0bbfa7af.
