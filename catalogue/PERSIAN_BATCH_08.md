# Persian translation batch 08

This batch adds Persian names and instructions for 450 independent imported
exercises (2,282 steps), increasing coverage from 1,068 to 1,518 of 4,308.
The assistant compared the names and 1,690 instructions to the pinned English
source; 592 instructions reuse translations for matching source text from
earlier batches. Independent review by an exercise specialist remains pending.

Exercises 3735, 4407 and 10932 were deferred for source ambiguity and replaced;
the deferred IDs from previous batches remain excluded. The manifest binds
source and translated text using SHA-256 hashes. Tests check the manifest,
instruction counts, uniqueness, bilingual search, English fallback, and previous
translations. Automated checks do not establish translation quality.

No exercise IDs, user data, saved plans, media, licenses or service worker
configuration are changed. The overlay grows by 275,018 bytes in source and
34,301 bytes gzip-compressed (source-file measurements; not a network benchmark).
The batch is based on commit 68b6384160c088afd0aab395e59c9b62d4e8f164.
