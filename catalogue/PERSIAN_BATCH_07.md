# Persian translation batch 07

This batch adds Persian names and complete instructions for 400 independent
imported exercises (2,079 steps), based on the pinned upstream English text.
It raises localization coverage from 668 to 1,068 of 4,308 imported exercises.
No catalogue IDs, English instructions, saved plans, media, or service worker
configuration are modified. Existing licenses and media notices remain in place.

The assistant compared the names and step text with the source. Matching
English instructions reuse prior translations. The final pass compared
940 retained or replacement steps and corrected 442 of the retained
draft steps. Record 9509 was deferred because its title and instructions
describe different movements. It was replaced with 0951 so the batch stays
at exactly 400 independent exercises. Other ambiguous records remain deferred.
Independent review by an exercise specialist remains pending.

The manifest binds every translation to its original name and step text with
SHA-256 hashes of compact UTF-8 JSON. Tests also verify instruction counts,
numeric values, bilingual lookup, English fallback and previous batch integrity.

The Persian overlay grows by 250,810 bytes as source JSON and
31,536 bytes when gzip-compressed. These are source file measurements.
