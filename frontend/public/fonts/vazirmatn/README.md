# Vazirmatn

Unmodified variable WOFF2 from Vazirmatn v33.003 by Saber Rastikerdar and
the Vazirmatn Project Authors. The font supports weights 100–900.

Upstream: https://github.com/rastikerdar/vazirmatn/tree/v33.003

Original file: `fonts/webfonts/Vazirmatn[wght].woff2`

The file is served locally with AliLab Training. No external font service is
needed. Its SIL Open Font License 1.1 and upstream author list are included in
`OFL.txt` and `AUTHORS.txt` alongside it. The font remains under that license.
